Developer & Wallet API

Zero-trust, on-chain anchor settlement oracle endpoints for Stellar wallets, routers, and DeFi protocols.

1. Pre-Flight Anchor Health Check

Stellar wallets (Vibrant, LOBSTR, Freighter) can call this endpoint prior to initiating SEP-24 deposits or SEP-31 cross-border remittances. If healthy is false, wallets should warn users or route to an alternate anchor rail.

GET /api/v1/anchors/{domain}/health-check

Returns the real-time reliability score (0–100), operational grade (A–F), and routing recommendation.

{
  "domain": "cowrie.exchange",
  "healthy": true,
  "score": 94,
  "grade": "A",
  "status": "optimal",
  "factors": {
    "liveness": 40,
    "settlement": 40,
    "volume": 14,
    "freshestHours": 2.1,
    "totalPayments": 489,
    "returnRatePercent": 0.4
  },
  "recommendation": "Excellent on-chain settlement health. Safe to route."
}

2. Dynamic SVG Status Badges

Embed auto-updating status badges on anchor documentation, GitHub repositories, or ecosystem directories.

GET /api/v1/badges/{domain}.svg

Example Markdown:

[![Landfall Status](https://landfall-ib.vercel.app/api/v1/badges/cowrie.exchange.svg)](https://landfall-ib.vercel.app/dashboard.html)
