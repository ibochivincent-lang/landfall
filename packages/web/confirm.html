What this is. A crypto transfer landed on-chain, but the fiat payment it was meant to trigger — a bank deposit, a mobile money credit — happens off-chain, where nothing here can see it. This form is the one way to close that gap that needs no cooperation from anyone else: the person who was supposed to receive the money says whether it arrived.

What it is not. Nobody is authenticated. There is no login, no identity check — this is one honest sentence from an unverified visitor, not a verified receipt. It only ever strengthens the record when the reporter identifies as the recipient; a sender's own report that they paid is not evidence the money arrived, and is recorded but never counted as such. Each transfer can be confirmed exactly once — the first submission stands permanently, so there is no path to quietly overwrite an earlier report.
Not checked against anything — it's context for whoever reads this later, not a verified figure.
