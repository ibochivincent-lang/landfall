Trust Check

Paste a Stellar address or transaction hash. See what the public ledger actually shows about it before you pay.

What this is, and isn't. Every signal below is computed live from Stellar's public ledger — nothing here is a fraud database, a scam list, or a reputation feed, because none exists that this project can independently verify. A flag is a ledger fact, never an accusation: the same pattern that looks like a risk can also be an ordinary automated wallet. Read the evidence, don't just read the color.
